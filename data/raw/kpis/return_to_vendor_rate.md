# KPI: Return to Vendor Rate
**Domain:** Operations | **Owner:** Operations Analytics | **Refresh:** Monthly
**Definition:** Percentage of received goods sent back to suppliers.
**Formula:** Units Returned to Vendor / Units Received × 100
**Source Tables:** fact_inventory
**Used In Reports:** Production Quality Dashboard (Power BI), Shipment Performance Report (SSRS)
**Notes:** Return to Vendor Rate is part of the Operations KPI catalog.
