# KPI: First Pass Yield
**Domain:** Operations | **Owner:** Operations Analytics | **Refresh:** Monthly
**Definition:** Percentage of units that pass quality checks the first time.
**Formula:** Units Passing First Time / Units Started × 100
**Source Tables:** fact_inventory, dim_product
**Used In Reports:** Supply Chain Dashboard (Power BI), Inventory Status Report (SSRS)
**Notes:** First Pass Yield is part of the Operations KPI catalog.
